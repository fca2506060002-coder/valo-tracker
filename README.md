# VALO RR Tracker

VALORANTの戦績スクリーンショットをOCRで解析し、
RR（ランクレーティング）を自動取得してデータベースに保存・管理するWebアプリです。

## 概要

VALORANTの試合結果を毎回手入力する手間を減らすため、
戦績画面のスクリーンショットからRRを自動で読み取る機能を実装しました。

取得したRRはデータベースに保存され、
戦績一覧やRR推移グラフから確認できます。

## 使用技術

- Laravel 13
- PHP 8.5
- MySQL
- JavaScript
- Tesseract.js
- Chart.js
- Docker / Laravel Sail
- Vite

## 主な機能

### 1. 戦績スクリーンショットアップロード

VALORANTの戦績画面のスクリーンショットを選択してアップロードします。

### 2. OCRによるRR自動検出

アップロードしたスクリーンショットから、
RRが表示されている部分を切り抜き、OCRによってRRを自動検出します。

例：

- +14
- +16
- -22
- -23

### 3. データベース保存

OCRで検出したRRをLaravelからMySQLへ保存します。

保存する主な情報：

- 試合日時
- 勝敗
- RR増減
- スクリーンショットの保存先

### 4. 戦績一覧

データベースに保存された戦績を一覧で確認できます。

### 5. RR集計

以下の情報を確認できます。

- 今日のRR
- 今週のRR
- 総試合数
- WIN数
- LOSS数

### 6. RR推移グラフ

Chart.jsを使用してRRの推移をグラフで表示します。

グラフは以下の単位に切り替えられます。

- 全期間
- 日ごと
- 週ごと
- 月ごと

## 操作方法

1. 「スクショを追加」を開く
2. VALORANTの戦績スクリーンショットを選択する
3. OCRによるRR解析が自動で開始される
4. 検出されたRRを確認する
5. 「スクショをアップロード」を押す
6. RRがデータベースに保存される
7. 戦績一覧で登録された結果を確認する
8. RR推移グラフで成績を確認する
9. グラフの表示を全期間・日・週・月に切り替える

## 工夫した点

戦績を手入力するのではなく、
スクリーンショットからOCRを利用してRRを自動取得することで、
入力の手間を減らせるようにしました。

また、OCRの誤認識を減らすため、
戦績画面全体ではなくRRが表示されている部分を切り抜いてから解析しています。

## 画面収録動画で行う操作

提出する画面収録動画では、以下の操作を行います。

1. VALO RR Trackerの戦績一覧画面を表示する
2. 「スクショを追加」を押す
3. VALORANTの戦績スクリーンショットを選択する
4. OCRによってRRが自動解析されることを確認する
5. 検出されたRRを確認する
6. 「スクショをアップロード」を押す
7. 検出したRRがデータベースに登録されたことを確認する
8. 戦績一覧画面で登録された戦績を確認する
9. 今日のRRと今週のRRを確認する
10. RR推移グラフを「全期間」「週ごと」「月ごと」に切り替える

## データベース連携について

アップロードした戦績スクリーンショットからOCRで取得したRRを、
Laravelを利用してMySQLのデータベースに保存しています。

保存した戦績はデータベースから取得し、
戦績一覧や今日・今週のRR、RR推移グラフとして表示しています。
